# ☕ ROAST — تجربة قهوة عصرية

## 🇸🇩 نبذة عن المشروع

**ROAST** هو موقع ويب عصري ومميز لمحبي القهوة، تم تصميمه ليقدم تجربة بصرية تركز على تفاصيل القهوة، من حبوب البن وحتى لحظة الاستمتاع بالفنجان.

الموقع يعتمد على تصميم حديث وحركات وانتقالات سلسة مع عرض بصري متتابع للصور لإظهار رحلة القهوة بطريقة تفاعلية.

## ✨ المميزات

- ☕ تصميم عصري ومميز مستوحى من عالم القهوة.
- 🫘 معرض صور لحبوب القهوة وتفاصيل التحضير.
- 🎞️ عرض متتابع للصور يحاكي رحلة القهوة.
- ✨ حركات وانتقالات بصرية سلسة.
- 📱 تصميم متجاوب مع الشاشات المختلفة.
- 🖥️ يعمل على أجهزة الكمبيوتر والهواتف.
- 🎨 واجهة مستخدم بسيطة وأنيقة.
- ⚡ أداء سريع بدون الاعتماد على مكتبات ضخمة.

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Responsive Web Design

## 🎯 فكرة المشروع

تم إنشاء ROAST كواجهة ويب تركز على **التجربة البصرية** بدلاً من مجرد عرض المعلومات، بحيث يشعر المستخدم بتفاصيل رحلة القهوة من الحبوب إلى الفنجان.

## 🚀 تشغيل المشروع

المشروع لا يحتاج إلى قاعدة بيانات أو خادم PHP.

يمكن تشغيله مباشرة عن طريق فتح:

```text
index.html
```

أو باستخدام أي خادم محلي مثل **Live Server** في Visual Studio Code.

## 📸 محتوى المشروع

يحتوي المشروع على:

- صور خاصة بالمعرض.
- صور متتابعة لعرض مراحل وتجربة القهوة.
- تأثيرات وحركات JavaScript.
- تصميم كامل باستخدام HTML وCSS.

# ☕ ROAST — A Modern Coffee Experience

## 📖 About the Project

**ROAST** is a modern and visually focused coffee website designed for coffee lovers.

The project focuses on creating an engaging visual experience around coffee, from coffee beans to the final moment of enjoying a cup.

The website combines modern design, smooth animations, transitions, and sequential image presentation to create an interactive coffee journey.

## ✨ Features

- ☕ Modern coffee-inspired design.
- 🫘 Coffee bean and preparation image gallery.
- 🎞️ Sequential image presentation.
- ✨ Smooth animations and transitions.
- 📱 Responsive design for different screen sizes.
- 🖥️ Desktop and mobile support.
- 🎨 Clean and elegant user interface.
- ⚡ Lightweight frontend implementation.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Responsive Web Design

## 📁 Project Structure

```text
roast/
├── assets/
│   └── images/
│       ├── gallery/
│       └── sequence/
│
├── css/
│   └── style.css
│
├── js/
│   ├── animations.js
│   ├── main.js
│   └── sequence.js
│
└── index.html
```

## 🎯 Project Concept

ROAST was built with a strong focus on **visual storytelling**, rather than simply presenting information.

The goal is to make the user experience the coffee journey through visuals, animations, and carefully designed interactions.

## 🚀 Getting Started

The project does not require a database or PHP server.

Simply open:

```text
index.html
```

Or run it using a local development server such as **Live Server** in Visual Studio Code.

## 📸 Project Content

The project includes:

- Coffee-themed gallery images.
- Sequential images representing the coffee experience.
- JavaScript animations and interactions.
- Complete HTML and CSS frontend design.
